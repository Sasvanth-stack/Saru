# Our Little Story

A frontend-only romantic microsite built with React, Vite, and Framer Motion.

## Run locally

```sh
npm install
npm run dev
```

## Personal photos

Add optional photos to `public/images/` using these filenames:

- `first-date.jpg`
- `birthday.jpg`
- `anniversary.jpg`

The page renders styled scenes when a photo is not present.
